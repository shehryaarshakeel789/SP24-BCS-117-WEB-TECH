# Lab Assignment 3

This app adds user authentication and role-based admin access to the e-commerce project.

## Setup

1. Install dependencies:
```bash
cd "Lab Assignment 3"
npm install
```
2. Seed initial data:
```bash
npm run seed
```
3. Start the app:
```bash
npm start
```

## Access
- Home: `http://localhost:3000`
- Admin login: `admin@example.com` / `admin123`
- Admin dashboard: `http://localhost:3000/admin`
